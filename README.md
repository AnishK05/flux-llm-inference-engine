# flux-llm-inference-engine

Production-style LLM inference platform: serving, continuous batching, KV-cache management, streaming generation, and observability.

**Target setup:** Windows laptop, **CPU only**, `Qwen/Qwen2.5-0.5B-Instruct`. Develop in WSL2.

This repository is in the planning stage. The full build plan (including locked product decisions) lives in [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md).
